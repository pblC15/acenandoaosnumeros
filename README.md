# Acenando aos Números
Landing page estática responsiva em HTML, Tailwind CSS e JavaScript. Abra `index.html` num navegador ou publique os ficheiros numa hospedagem estática.

## Publicação em Nginx
Copie `index.html` e a pasta `assets/` para a raiz do site. Não é necessário Node.js ou build.

## Configuração pendente
- Substituir o botão secundário de redes sociais pelo endereço oficial do Facebook quando disponibilizado.
- Confirmar se o Instagram `https://www.instagram.com/acenandoaosnumeros/` é o perfil oficial.
- Tailwind CSS, Lucide e fontes Google são carregados por CDN, pelo que requerem ligação à Internet.
